# 1600主教师＋C0补充：新蒸馏小Actor

本包部署一个31→128→64→32→6 ELU/Tanh Actor，14,630参数。运动主要模仿冻结1600；静态与部分接扰由冻结C0补充监督。每个监督样本只使用一位教师动作。部署仅运行新学生，不运行双教师选择器。

输入保持31D、绝对腿q与实际采用previous腿目标÷1.5、previous轮目标÷100、真实dq×.05；六通道为模型left hip/active/wheel、right hip/active/wheel，模型left为几何右，不交换数组。输出为冻结C0承重中心＋腿±0.15rad，轮±80rad/s。网络末层Tanh只执行一次。

31D展开（float32[1,31]）：

|索引|内容|
|---|---|
|0–2|模型机体gyro(rad/s)×0.25|
|3–5|同坐标系单位重力，直立为[0,-1,0]|
|6–9|四腿绝对q[ch0,ch1,ch3,ch4]÷1.5|
|10–15|六关节真实dq(rad/s)×0.05|
|16–19|实际采用四腿目标[ch0,ch1,ch3,ch4]÷1.5|
|20–21|实际采用轮目标[ch2,ch5]÷100|
|22–24|vx÷4、yaw速度÷4、目标高度÷0.5|
|25–30|Motion/NONE固定[1,0,0,1,0,0]|

坐标沿用原C0标定；模型+Y向上、-Z向前、-X向几何左。零位、轴正向及传动比不由本新权重改变。输出float32[1,6]确定性mean，末层已有Tanh，不再Tanh或采样std；四腿为绝对位置目标、两轮为速度目标。

验证范围固定0.34m、完整V4、Actor物理字段20ms、目标5ms、几何右轮7ms／左轮11ms且tau0；物理/PD/策略1/5/10ms、PD40/2/.2。仿真轮实际限矩2.446947864Nm。实机使用最新有效反馈，不人为增加仿真延迟；previous只由实际采用层更新。

双轮同时承重低于90%不合格。站立、直线、自转、腿模态扰动与机体推扰结果见capability_evidence.json和训练run的最终报告。模仿教师的未合格工况不转成绝对通过；数学高度定义域不等于已经验证的高度能力。

当前教师与SHA以student.pt的source_teachers为准。初始化所继承的2320来源字段已移入initialization_ancestor_metadata，只作历史追溯。导出前后Actor逐tensor、输出合同与执行时序精确相同。

PT/ONNX/C与物理解码、PD的golden核对见verification.json。encoder delta仍UNKNOWN。本包未安装固件、未刷板；板端实时性与实机闭环尚未验证。
