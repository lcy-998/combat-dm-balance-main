# C0连续高度公式试验包

Actor权重仍为C0，31→128→64→32→6、ELU/Tanh。原包`../motion_C0_standing_trial`保留。
本包活动接口以output_contract.json及firmware_binding.json为准；PT内嵌合同只代表来源，不能当作新解码合同。ONNX metadata已更新为本活动接口，学习权重未变。

中心为解析几何加全局五次多项式，不在运行时查表。x=(h-.35)/.05，两个偏移多项式采用低次到高次的6项系数，见center_fit.json。
六个原始锚点保持；锚点间较原表插值最多差.003870rad/髋、.001535rad/主动。Kp40对应最大请求差约.155/.061Nm。

`ChassisSetRLHeight(h)`可直接设绝对命令高度；原changeL拨杆沿用原每周期.002*.03m步进。

同一Actor请求按其输入的高度计算中心。即使当前高度命令改变，旧在途包仍保持原来的物理目标，不按新高度重解码；实际采用后才更新绝对previous。腿PD=40*(实际采用绝对目标-q_model)-2*dq，轮PD=.2*(轮目标-dq)，均不额外扣中心。
零位、输入1.5/100、真实dq、.15/80输出尺度、PD增益与限矩不改；delta仍UNKNOWN。

本包CPU数值对照不代表动态调高已做闭环或实机验证。原C0的站立/直线能力只作来源证据；转向/+3m/s缺口不因换公式消失。
